# The-Smart-Fitness
A fitness gym landing page designed using HTML and CSS.This project is built as part of learning web development to create clean user interfaces and registration forms.
## About the Project
This project is a single-page web layout for a fitness gym. It includes:
- A attractive background banner.
- A navigation menu.
- Quick contact buttons ("Call Us Now" and "Email Us").
- A membership registration form to collect user details (Name, Age, Gender, Locality, Email, and Phone No.).
